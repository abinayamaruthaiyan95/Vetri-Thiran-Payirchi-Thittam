# Test Cases

1. User with `bb1` can view EEE branch records.
2. User without the required role cannot view records.
3. Admin can view all records.
4. User with `bb1` + `bb2` can create records.
5. User with `bb1` + `bb2` + `bb3` can edit records.
6. User with `bb1` + `bb2` + `bb3` + `bb4` can delete records.

Verify these cases by impersonating the relevant users in ServiceNow.
